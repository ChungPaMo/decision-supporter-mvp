# 작은 손계산 케이스 풀이 (SYNTHETIC)

규칙: [PLANNING_RULES.md](../../PLANNING_RULES.md) v0.3. 입력과 정답은 [small_cases.json](small_cases.json)에 있다.
모두 손으로 풀 수 있는 크기다. 케이스마다 규칙 하나를 확인한다. 엔진이 틀리면 어느 규칙이 틀렸는지 바로 알 수 있게 하려는 것이다.

| 케이스 | 확인하는 규칙 | 판정 |
|---|---|---|
| HC-01 | 할당재고·안전재고·수요 올림 | FEASIBLE |
| HC-02 | 앞 달 미리 생산 → 남으면 뒤 달 보충 → 결품 이월, 안전재고 SOFT | INFEASIBLE |
| HC-03 | 공유 설비를 같은 비율로 축소, 자투리 시간은 다시 나누지 않음 | INFEASIBLE |
| HC-04 | 제품마다 가장 빠듯한 자원의 비율을 따름 | INFEASIBLE |
| HC-05 | 잔업 사용 | FEASIBLE |
| HC-06 | 잔업 허용 안은 그달 잔업 먼저 | FEASIBLE |
| HC-07 | 같은 입력, 잔업 없는 안 → 결품 | INFEASIBLE |
| HC-08 | 월 생산수량 한도 | FEASIBLE |
| HC-09 | BOM 전개·자재 부족·입고 예정 | UNVERIFIED |
| HC-10 | What-if 수요배수 | 기준 FEASIBLE → INFEASIBLE |
| HC-11 | 라우팅 빠짐 | UNVERIFIED |
| HC-12 | 단위 오류 | INPUT_INVALID |

공통: 1개당 시간 h = run_time ÷ reference_qty. 생산량 P = ⌊X × 비율⌋.

## HC-01 기본 순소요

제품 A: 현재고 40, 할당 10 → **가용재고 I₀ = 30**. 안전재고 20. 설비 S: 10개에 1시간 → h = 0.1. 정규 100시간.

| | 1월 | 2월 | 3월 |
|---|---|---|---|
| 예측 | 100.4 | 120 | 89.2 |
| 계획 수요 d = ⌈예측⌉ | **101** | 120 | **90** |
| 목표 T = max(0, d + 20 − J) | 101 + 20 − 30 = **91** | 120 + 20 − 20 = 120 | 90 + 20 − 20 = 90 |
| J (계획상 재고) | 30 + 91 − 101 = 20 | 20 | 20 |
| 부하 = T × 0.1 | 9.1 ≤ 100 | 12 | 9 |
| 생산 P | 91 | 120 | 90 |
| 월말 재고 I | 20 | 20 | 20 |

모든 판정 SATISFIED → **FEASIBLE**.

## HC-02 설비 한도·선행생산·보충·결품

A: I₀ = 0, 안전재고 10. h = 1. 정규 100 / 80 / 100, 잔업 없음.

**① 목표**: T₁ = 100 + 10 − 0 = 110 (J₁ = 10), T₂ = 100 + 10 − 10 = 100, T₃ = 50

**② 뒤에서부터**

| 순서 | X | CAP | 비율 | P | 넘친 양 |
|---|---|---|---|---|---|
| 3월 | 50 | 100 | 1 | 50 | 0 |
| 2월 | 100 | 80 | 0.8 | 80 | 20 → 1월로 |
| 1월 | 110 + 20 = 130 | 100 | 100/130 | 100 | **30 → 못 만든 양 U** |

**③ 보충** (앞에서부터): 2월 남은 시간 80 − 80 = 0 → 없음. 3월 남은 시간 100 − 50 = 50 → 30 모두 보충 → P₃ = 80

**④ 재고**: I₁ = 0 + 100 − 100 = 0, I₂ = 0 + 80 − 100 = **−20 (결품 20)**, I₃ = −20 + 80 − 50 = 10

| 판정 | 1월 | 2월 | 3월 |
|---|---|---|---|
| CAP (사용/한도) | 100/100 BINDING | 80/80 BINDING | 80/100 |
| DEM | SATISFIED | **VIOLATED** | SATISFIED |
| SS (재고 ≥ 10) | VIOLATED (0) | VIOLATED (−20) | SATISFIED (10) |

HARD(DEM) 위반 → **INFEASIBLE**. SS는 SOFT라 판정에 영향 없음.

## HC-03 공유 설비 같은 비율

A(수요 60): S 1시간 + RA 1시간. B(수요 40): S 4시간/2개 = 2시간. S 정규 120, RA 정규 100.

- 부하: S = 60×1 + 40×2 = **140** > 120 → 비율 120/140 = **6/7**. RA = 60 ≤ 100 → 비율 1
- A 비율 = min(6/7, 1) = 6/7 → P = ⌊60 × 6/7⌋ = ⌊51.43⌋ = **51**
- B 비율 = 6/7 → P = ⌊40 × 6/7⌋ = ⌊34.29⌋ = **34**
- S 사용 = 51 + 68 = **119** (자투리 1시간은 다시 나누지 않는다)
- 결품: A 9, B 6 → **INFEASIBLE**

## HC-04 여러 자원 중 가장 빠듯한 것

HC-03과 같고 RA 정규만 **45**.

- 비율: S = 6/7, RA = 45/60 = **3/4**
- A는 S·RA 둘 다 씀 → min(6/7, 3/4) = 3/4 → P = 45. B는 S만 씀 → 6/7 → P = 34
- S 사용 = 45 + 68 = 113 (A가 RA 때문에 줄어서 S가 7시간 남지만 다시 나누지 않음)
- 결품: A 15, B 6 → **INFEASIBLE**

## HC-05 잔업

A 수요 110, h = 1, 정규 100 + 잔업 20 = CAP 120.
110 ≤ 120 → P = 110. 잔업시간 = 110 − 100 = **10**. **FEASIBLE**.

## HC-06 잔업 먼저, 남는 것만 앞 달로 (잔업 허용)

A 수요 80 / 140, 정규 100 + 잔업 20 (두 달 모두).

| 순서 | X | CAP | P | 넘친 양 |
|---|---|---|---|---|
| 2월 | 140 | 120 | 120 | 20 → 1월 |
| 1월 | 80 + 20 = 100 | 120 | 100 | 0 |

잔업: 1월 0, 2월 **20**. 재고 20 → 0. **FEASIBLE**.
1월 정규시간이 20 남지만 2월 잔업을 먼저 쓴다. 미리 만들면 재고가 쌓이기 때문이다(규칙 §3.2).

## HC-07 같은 입력, 잔업 없음 (비용절감형)

CAP = 정규 100 / 100.

| 순서 | X | CAP | P | 넘친 양 |
|---|---|---|---|---|
| 2월 | 140 | 100 | 100 | 40 → 1월 |
| 1월 | 80 + 40 = 120 | 100 | 100 | **20 → U** |

보충: 2월 남은 시간 0 → 없음. 재고: I₁ = 20, I₂ = 20 + 100 − 140 = **−20** → 결품 20 → **INFEASIBLE**.

## HC-08 월 생산수량 한도

G 수요 30 / 70, 월 한도 50 / 50. 설비는 넉넉함.

| 순서 | X | 한도 비율 | P | 넘친 양 |
|---|---|---|---|---|
| 2월 | 70 | 50/70 | 50 | 20 → 1월 |
| 1월 | 30 + 20 = 50 | 50/50 = 1 | 50 | 0 |

재고 20 → 0. QTY-G-02만 BINDING(1월은 넘치지 않음). **FEASIBLE**.

## HC-09 BOM 전개·자재 부족

A 생산 100 / 100 (설비 넉넉).
- K1: 소요 2 ÷ 기준수량 1 × (1 + 0.05) = **2.1** /개. 재고 150, 안전재고 20, 2월 입고 예정 100
- K2: 3 ÷ 2 × (1 + 0) = **1.5** /개. 재고 400, 안전재고 0

| K1 | 1월 | 2월 |
|---|---|---|
| 월 소요 N = 100 × 2.1 | 210 | 210 |
| 누적 소요 CN | 210 | 420 |
| 누적 가용 AV = 150 + 입고 − 20 | 130 | 230 |
| 누적 부족 SH | 80 | 190 |
| **그달 부족** | **80** | **110** |
| available (그달 새로 생긴 가용) | 130 | 100 |
| 판정 | UNVERIFIED | UNVERIFIED |

K2: 누적 소요 150 / 300 ≤ 400 → 부족 0, SATISFIED.
결품은 없고 HARD 중 UNVERIFIED만 있음 → **UNVERIFIED** (조달 필요).

## HC-10 What-if 수요배수 1.2

A 예측 100.3, S 정규 110.
- 기준: d = ⌈100.3⌉ = 101 ≤ 110 → P = 101, **FEASIBLE**
- What-if: d = ⌈100.3 × 1.2⌉ = ⌈120.36⌉ = **121** → 110시간까지만 → P = 110, 결품 11 → **INFEASIBLE**

배수는 올림 **전에** 곱한다(⌈100.3⌉ × 1.2 = 121.2 → 122가 아님).

## HC-11 라우팅 빠짐

A(수요 50)는 S를 씀, B(수요 30)는 라우팅이 없음. S 정규 100.
- B는 설비 계산을 건너뛰고 P = T = 30. A는 50 ≤ 100 → P = 50
- B가 S를 쓰는지 알 수 없으므로 CAP-S-2027-01은 **UNVERIFIED**(MISSING_INPUT, 사용시간 null), unverified에 `ROUTING_MISSING`
- 결품 없음, HARD 중 UNVERIFIED 있음 → **UNVERIFIED**. 계산은 했으므로 status는 OK

## HC-12 단위 오류

A 수요는 EA인데 재고 단위가 kg → 서로 뺄 수 없음. 계산하지 않고 status **INPUT_INVALID**, error `UNIT_MISMATCH`, 계획안 없음.
